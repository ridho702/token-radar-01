Token Launch Radar

614 protocols that record no token, ranked by implied value — fair value from a regression fitted on 144 token protocols, times the odds of launching, from peers' track record. Snapshot 2026-11-14.

How this radar works

Stage 1 fits log(market cap) = a + b·log(TVL) on the 144 protocols whose token trades (128 with mcap > 0 and TVL > 0; 15 with mcap = 0 are dead tokens and are excluded). Stage 2 fits the residual on 7-day growth and log(age) — growth and age move the multiple only slightly in the data, so their effect is shrunk ×0.5 and clamped. Token odds come from each category's launch rate (shrunk toward the global 19%) times an age-band factor. Implied value = fair value × odds — an expected value, not a prediction of if or when a token launches. No protocol name is hardcoded. Growth is in percent in the snapshot (÷100, clamped −0.9…+5.0); a missing listing date counts as 365 days. Gas figures are planning estimates, not live quotes.
