How this radar works

Value model. A log-log regression fitted on the 144 token-bearing protocols in this snapshot: log(market cap) = intercept + slope × log(TVL), plus a small second-stage adjustment for 7-day growth and protocol age (coefficients halved, total clamped to ±0.35 log points; the second stage's intercept is not applied). The model uses a pooled intercept: category-specific intercepts were also fitted, but they did not beat pooled on unseen data, so the pooled model is used.

Odds. A protocol's chance of launching a token is estimated from its peers: its category's token rate, shrunk toward the 19% global rate, times an age-band factor (young protocols launch far less often), clamped to 2–50%.

Expected value. Implied value = fitted fair value × odds. It is what a token would be worth if one launched and the protocol's record stayed as it is — not a prediction that one will launch, or when.

Farm plans. Six concrete steps per protocol, in English, with amounts per tier (Small $100 / Medium $1,000 / Large $10,000), gas and time. Gas is a planning estimate, not a live quote.

Integrity strip

A pre-token protocol is left off this board when another protocol with the same brand stem already has a token trading.
